ℹ️ Instructions

1. Record responses

Choose the group, number of students, and subject. For every item, tap CORRECT or INCORRECT once per learner, then tap NEXT ITEM.

2. Export a group

From Results, use Export All 8 Subjects. Send the JSON file to the teacher device.

3. Consolidate five groups

On the teacher device, import the five group files. The Results page automatically adds the frequencies.

4. Independent teacher copies

Other teachers can use your GitHub repository's Use this template button to create their own independent copy.
