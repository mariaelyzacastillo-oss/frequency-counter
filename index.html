ℹ️ How Live Mode Works

Teacher

Tap Create Teacher Session. A 6-character code appears. Keep the Teacher Dashboard open.

Groups

Each group opens the same website, enters the session code, chooses its group, and records responses.

Real-time

Every response is synchronized to Firebase. The teacher dashboard updates automatically.

Internet

Live synchronization requires an internet connection. The app can queue local database operations during brief disconnections and synchronize when connectivity returns.
